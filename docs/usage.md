# 操作リファレンス

[README](../README.md) の使い方の全量版。キーボードショートカットはアプリ内でも `?` キーで同じ一覧が開く。

## キーボードショートカット

#### 検索

| キー | 動作 |
|------|------|
| `Enter` | 検索実行 |
| `Alt+C` | 大文字小文字を区別 |
| `Alt+W` | 単語単位で検索 |
| `Alt+R` | 正規表現モード |
| `Alt+H` | 検索履歴を表示 |
| `Ctrl+Enter` | 現在の検索結果をスタックに保存（検索欄にフォーカス時） |
| `Alt+Shift+S` | 検索スタック一覧を表示 |
| `↑` / `↓` / `Enter` | 結果一覧にいるとき: 候補を選ぶ / 選んでコードへ |

#### エディタ

| キー | 動作 |
|------|------|
| `Alt+A` / `Alt+クリック` | カーソル位置のアクションを一覧（定義・参照・呼び先・grep と履歴の戻る/進む。一覧の文字がそのまま直キー） |
| `Alt+D` / `F12` / `Ctrl+クリック` | 定義ジャンプ |
| `Alt+R` / `Shift+F12` | 参照ピッカー（入力のたびに索引全体へ絞り込み。空白で AND / `-語` で除外 / `path:…` でパス限定） |
| `Alt+C` | カーソルがいる関数の呼び先一覧（語ではなく囲む関数が対象） |
| `Alt+E` | 定義をその場で見る（Floating Peek） |
| `Alt+W` | この語へ書き込んでいる場所（代入・複合代入・++/--） |
| `Alt+G` | カーソル位置の単語を grep 検索 |
| `Alt+T` | コールツリーで検索 |
| `Alt+F` | 確認中の一覧を開き直す（並び順そのまま・現在地に色） |
| `Alt+V` | 移動の履歴を一覧表示（現在地をハイライト、開いたまま `Z` / `X` で移動） |
| `Alt+Z` / `Alt+X` / `Alt+←` / `Alt+→` | 閲覧履歴を前後に移動 |
| `Ctrl+P` | ファイルクイックオープン（fzf スタイル、`#` 始まりでシンボル検索） |
| `Alt+Shift+T` | シンボル名で定義へジャンプ |
| `F3` / `Shift+F3` | 検索結果を次 / 前へジャンプ（ピッカーから選んだ直後はその一覧を順送り） |
| `Alt+H` | カーソル位置の単語を追跡ハイライト / 解除 |
| `Alt+N` | 行メモを追加 / 編集 |
| `Alt+M` | 行メモのインライン表示切り替え |
| `Alt+P` | デバッグ行を挿入（エディタ内） |
| `Alt+Shift+P` | ファイルパス表示切り替え |
| `Alt+Shift+E` | 外部エディタで開く |
| `Alt+Shift+G` | 選択テキストをグラフノードに追加 |
| `右クリック` | 基数変換電卓（マクロ名入りの式も計算） |

#### ツリー

| キー | 動作 |
|------|------|
| `Alt+Shift+G` | エディタの選択テキストをノードに追加 |
| `Alt+Shift+N` | ツリーメモのインライン表示切り替え |
| `↑` / `↓` | 選択ノードを変更 |
| `Shift+Alt+↑` / `↓` | 選択ノードを上 / 下に移動 |
| `Shift+Alt+←` / `→` | 選択ノードのレベルを上げる / 下げる |

#### 全体

| キー | 動作 |
|------|------|
| `Ctrl+S` | プロジェクトを保存 |
| `Ctrl+Z` | 元に戻す |
| `Ctrl+Shift+N` | 新しいウィンドウを開く |
| `?` | キーボードショートカット一覧を表示 |

## Ctrl+P ファイル検索

スペース区切りで AND 絞り込みができます。

```
ssl bio        → "ssl" かつ "bio" を含むパスを表示
test connect   → test ディレクトリの connect 関連ファイルを表示
```

## Alt+Shift+T シンボル検索

関数・マクロ・typedef を名前で検索して定義へジャンプします（ctags 索引が必要）。スペース区切りは順序付きの部分一致になります。

```
recipe save    → recipe_save / RecipeSaveAll など「recipe…save」の順で含むシンボル
#recipe save   → Ctrl+P のファイル検索からそのまま切り替える書き方
```

候補には種別バッジ（f=関数 / d=マクロ / t=typedef 等）と定義位置が表示され、Enter で定義行へジャンプします。

## 検索結果の絞り込み

検索後に **絞り込みバー** でさらに絞れます。

```
foo bar        → AND 検索（foo かつ bar を含む行）
foo|bar        → OR 検索
-test          → test を含む行を除外
file:bio       → ファイル名に bio を含むものだけ
path:crypto    → パスに crypto を含むものだけ（ディレクトリ含む）
-file:test     → ファイル名に test を含むものを除外
```

絞り込み欄の `?` ボタンで全構文のチートシートが表示されます。

## ノード移動

**ドラッグ&ドロップ**
- ノード行をドラッグして他のノードにドロップ → 子ノードにする
- 別のノードの上端/下端にドロップ → 前後の兄弟として挿入（ターコイズのラインで位置を確認）
- 左上の「ここにドロップ」ゾーンにドロップ → ルートに移動

**⠿ ハンドル**
- ノード行の左端の `⠿` を左右にドラッグ → インデントレベル（階層）を変更
- ドラッグ中はレベル変化がバッジで表示される

**キーボード**
- Shift+Alt+Arrow キーで選択ノードを移動（↑↓ で兄弟間、← でレベルアップ、→ でレベルダウン）

## 表示モード

エディタペインを畳んだレイアウトに切り替えられます。**設定（⚙）の「表示モード」**から選ぶか、URL パラメータで指定します。

| モード | 表示 | 選び方 |
|-----|------|------|
| 通常 | 検索 + ツリー + エディタ | 既定 |
| 検索のみ | 検索パネルだけ | 設定 または `?mode=search` |

設定で選んだモードは次回起動時も維持されます（`?mode=` を付けて開いた窓では URL が優先されます）。デスクトップ版の窓にはアドレスバーが無いため、そちらは設定から切り替えてください。

検索のみモードではエディタペインが無いため、検索結果を開くと外部エディタが起動します。**grep と呼び出し元の追跡だけを grepnavi に任せ、編集は普段のエディタで**、という使い方になります。VSCode の Simple Browser に `?mode=search` を入れておくと、エディタの横に検索パネルを置けます。

## プロジェクトファイル

調査内容は JSON ファイルに保存されます。

```json
{
  "version": 2,
  "root_dir": "/path/to/project",
  "active_tree_id": "...",
  "trees": [
    {
      "id": "...",
      "name": "ツリー1",
      "nodes": { ... },
      "edges": [ ... ]
    }
  ],
  "line_memos": {
    "ファイルパス:行番号": "メモ内容"
  }
}
```
